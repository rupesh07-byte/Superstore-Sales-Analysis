# Superstore Sales & Profit Analysis 📊

## 📌 Project Overview
This project analyzes Superstore sales data to understand revenue, profit, category performance, regional contribution, and monthly trends using Excel, SQL, Python, and Power BI.

---

## 🛠 Tools & Technologies Used
- **Excel** – Initial data exploration and validation  
- **SQL (MySQL)** – Data storage and analysis  
- **Python (Pandas, Matplotlib)** – Data validation and analysis  
- **Power BI** – Interactive dashboard and visualization

## 📈 Key Insights
- Technology category contributes the highest sales
- West region has the maximum sales contribution
- Consistent sales growth observed towards year-end
- All sub-categories are profitable (no negative profit)

---

## 📊 Power BI Dashboard Highlights
- Total Sales & Total Profit KPIs
- Sales by Category
- Profit by Sub-Category
- Sales Contribution by Region
- Monthly Sales Trend
- Interactive slicers (Category & Region)
